# Lokad.Lython core

The managed Python frontend and executable runtime target .NET 10. Public API
types are under `Public/`; host capabilities and the regex contract are under
`Host/`. The optional Utf8Regex adapter is a separate project.

See the [documentation index](../../docs/README.md),
[architecture](../../docs/ARCHITECTURE.md) and
[embedding contract](../../docs/RUNTIME.md).
