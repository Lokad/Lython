instruction stream. A register renaming alone keeps snapshots/transport; small
argument buffers already pool and double as final locals. Instead move control-flow
stack-shape knowledge into compilation and delete three runtime mechanisms together:
resizable operand buffers/Push admission retries, per-frame block-entry depth arrays,
and the nested block/instruction dispatch driver. Keep guest object representation,
stable contexts/frames, final-slot binding, native helpers and genuine async operations.
No alternate backend or shared mutable activation pool.

Hypothesis: less runtime transport/control bookkeeping plus pre-sized storage improves
complete CSV/text helpers; this is not proven by B65 self counts. Compile each
reachable instruction/edge, including exception/finally entries, iterator exhaustion,
protected break/continue, yield/send/delegation, expanded calls/displays, class headers,
annotations and hidden type-subscription temporaries. Preserve all necessary value
snapshots and temporary cursor disposal. Invalid internal shapes are compiler defects,
never fallback selection. First prove all supported shapes, then replace retained
block graphs with linear instructions/absolute control ranges in the same engine.

Contract tradeoff: fund the whole conservative maximum operand capacity before frame
construction; admission can fail earlier than lazy growth. Borrow the same allowance,
keep first origin, checked arithmetic and actual managed array bounds, and keep every
live cursor/result/alias/pending operation funded through awaited cleanup. No retry,
new quota/allowance, tracing or ownership infrastructure. Current-token checkpoints,
managed nesting admission and native preflights remain. Remove the old growth/depth/
block paths completely if retained. No public option or guest syntax change.

Semantic acceptance: existing ordinary functions/defaults/keywords/classes, closure
identity/introspection, evaluation order and rebinding, generator send/throw/close,
exception/finally/context suppression, actual async host/protocol suspension, cancellation
in nonallocating loops, terminal first-refusal/effects and shared-budget balances.

layout. Stop before timing if the shape proof requires a second engine or broad
