# B1686 Share the admitted default writer

The private candidate makes ordinary executable, closed, lowered and
generated definitions write into the same admitted owner slot. One writer
classifies that slot and replaces just the selected singleton. The duplicate
destination classifier and whole-default assignment paths disappear. Both
initial preflights, any larger scalar charge, evaluation order and rollback
remain. The source pair differs by five core files and removes 12 net lines.

Both images match eight complete CPython 3.13.2 goldens, 219 executable
bodies and 2,107 instructions, including source spans and retained compiler
admission. Local warm allocation is effectively flat, and all execution
peaks and allowance balances match. Windows passes 697 public Release
checks per target. Ubuntu .NET 11 passes 697 public and 120 white-box checks.
The initial private sparse checkout lacked `benchmarks/scripts`. Restoring
those tracked fixtures clears two missing-file failures on both platforms.
The implementation and assertions stay the same.
