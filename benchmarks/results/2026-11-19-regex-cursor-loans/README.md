# Development regex cursor loans with dev.107

An optional adapter prototype used the immutable Core and PythonRe
0.5.0-dev.107 packages from `7be42c66`. The core and parent regex
test binaries are the existing dev.106 qualification images. Package,
target assembly and parent/child hashes were checked against the
recorded inputs.

The cursor borrows one working reservation from its Lython owner.
It forwards the creation token while preparing the cursor, detaches
the registration on return and supplies each pull's actual token to
the producer. Each pull keeps the producer's range receipt through
the copy into caller slots, then disposes it before returning.

The direct funding probe passes on .NET 11 and .NET 10. It cancels
the earlier preparation token, checks subsequent capture coordinates
and observes producer growth and release. A requested 224-byte working
growth is refused exactly once and the original refusal is reported.
Working storage returns to zero, and a later cursor uses the same
owner successfully.

The first .NET 11 suite passed 361 of 363 cases. The old match and
cursor cancellation inputs completed before cancellation could fire
on dev.107. The recalibrated development worker scans a large Unicode
subject with a simple pattern and keeps the original cancellation
assertions and timeout. It demonstrated in-flight cancellation in
compilation, matching and cursor advance, with the current token and
a zero balance. The suite passed all 363 cases on each target with
that worker. Both sets of results are preserved.

The regular adapter and its 0.4.0 dependency pin remain as shipped.
Final package and managed-safety qualification remain open.
These results cover correctness and lifetimes, with backend timing
unmeasured.
